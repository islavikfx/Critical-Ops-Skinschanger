## Critical Ops Skinsсhanger

Works only with rooted devices and Game Guardian.

![Menu](https://github.com/islavikfx/Critical-Ops-Skinschanger/blob/main/img/menu.png?raw=true)

Skin IDs are stored in:  
`/data/app/com.criticalforceentertainment.criticalops-xxx==/base.apk/assets/bin/Data/b9225992870ce094dbe590033320ec95`

The 'skins_parser.py' script works with Python3 and can extract and sort IDs and weapon names from the system directory into a '.lua' menu for Game Guardian.

Your can improve the skinchanger if you want - just leave my credits if possible, thank you. Some menus may crash your game when selecting custom skins because the Python parser also includes animations IDs.

In Game Guardian settings, you can tap 'Fix It' and choose **'Context'** - **'Instrumentation'** to avoid background detection. In this menu, you can also select **'Switch to work with SELinux'** if Game Guardian is restarting your device.
